# AGENTS.md: schema for this wiki

This is an OKF v0.3 bundle compiled by an LLM from 16 research papers. It holds no paper text, only LLM-written pages and DOI links.

## Layout
- `index.md`: root index. `sources/index.md` and `topics/index.md` list the pages in each folder.
- `sources/<paper-id>.md`: one summary page per paper (`type: Source Summary`).
- `topics/<slug>.md`: pages that connect papers: concepts, methods, findings, debates (`type: Topic`).
- `log.md`: one `## YYYY-MM-DD` heading per day, newest first, one bullet per event.

## Conventions
- Every fact carries a footnote marker `[^<paper-id>-p<page>]` that points to one page of one paper.
- The footnote definitions and the `sources` list are generated by code from the markers. The LLM writes only the title, description and body.
- Links between pages are standard markdown links, relative to the file. No `[[wikilinks]]`.
- Nothing here is human-verified, so there are no `verified` entries.

## Operations
- Ingest: one paper at a time. Write the source page, choose up to 5 topics, rewrite each in full.
- Query: read the indexes, choose up to 6 pages, answer from them with citations `[<paper-id>, p.<N>]`.
